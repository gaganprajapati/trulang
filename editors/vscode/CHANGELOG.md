# Change Log

## [0.1.0] - 2026-10-16

- Initial release of official TruLang Visual Studio Code extension.
- Complete TextMate syntax highlighting for `.tr` files.
- Full Language Server Protocol client integration with `trulang lsp`.
- Real-time syntax and type diagnostics publishing.
- Hover information, go to definition, and document formatting.
- Quick commands for running and type-checking active files.
